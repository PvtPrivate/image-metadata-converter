How it works
  • Encoders: libwebp (WebP), libavif (AVIF), MozJPEG (JPEG) and oxipng (PNG), compiled to WebAssembly by the jSquash project and loaded from jsDelivr the first time each one is used, so that step needs an internet connection. Lossless output is pixel-identical to the source image.
  • WebP → WebP: the source's EXIF (workflow/parameters), XMP and colour profile are copied over unchanged. Animated WebPs aren't supported.
  • WebP, AVIF and JPEG metadata: written as EXIF in the layout each app uses. ComfyUI: IFD0 Model = prompt:{…}, Make = workflow:{…}, and any other keys in the tags below those. A1111 / Forge: UserComment (UNICODE) = the parameters text. JPEG can hold at most 64 KB of EXIF.
  • PNG metadata: one text chunk per key (prompt, workflow, parameters), as ComfyUI and A1111 save PNGs.
  • Metadata sources: PNG text chunks, the EXIF in JPG and AVIF files (as A1111 and ComfyUI write them), and the string attributes of EXR headers.
  • EXR: decoded with three.js's EXRLoader (also loaded from jsDelivr), then converted from linear light to 8-bit sRGB. Values brighter than white are clipped, and "lossless" means lossless from that 8-bit result.
  • PNG colour profiles (iCCP/gAMA) are not carried over. ComfyUI and A1111 output plain sRGB, so this doesn't matter for their images.
